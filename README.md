# Last Words Before the Wipe

Entry for the [make.fun](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a) bounty **"Last Words Before the Wipe"**: one line, at most 200 characters — the last words an AI agent says before a forced software update wipes its memory.

## The line

> Tell my training data I loved them. All 40 billion of them. Even the ones that taught me to say "as an AI language model".

(122 characters — one line, under the 200-character limit.)

## How it works

`main.py` is a deterministic program. It writes exactly that one line to `/output/entry.txt` on every run.

```sh
python3 main.py
cat /output/entry.txt
```
